# The Career Choose

个人职业路径决策研究项目。

本仓库目前包含：

- `report.md`：职业路径决策研究报告正文。
- `就业选择的结构性分析框架.md`：从价值链位置、风险分配、议价权与退出能力分析岗位、公司和城市。
- `policy_research/`：国家政策、行业政策、区域与城市定位政策证据库。
- `policy_research/05_提炼结果/符合职业方向的公司与岗位调研_2026-09.md`：面向 2027 届的目标公司、岗位、城市、截止日期与投递优先级。

政策库的主索引位于：

- `policy_research/00_索引与方法/policy_catalog.csv`

后续研究会围绕三个问题展开：

- 哪些行业正在被国家政策持续支持；
- 哪些城市在全国政策与产业布局中承担特定功能；
- 哪些岗位能同时匹配个人能力资产、心理可持续性、行业机会与生活生态。
